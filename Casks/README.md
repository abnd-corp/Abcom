# Abcom Homebrew tap

Casks are generated from published GitHub release artifacts, with a pinned version,
URL and SHA-256. No public beta release exists yet, so no installable cask is
advertised here. The first release will propose `abcom.rb` through a PR to `dev`;
after promotion to `main`, the commands in the [installation guide](../packaging/README.md#homebrew-on-macos)
will work against this repository. No Homebrew catalogue submission is required.

See the [French guide](../packaging/README.fr.md#homebrew-sur-macos).
